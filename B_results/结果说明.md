## 1. 第一问：光谱去异常与连续重构

### 方法
1. log 光谱矩阵分解为 **X = L + S + N**：L 为低秩（真实信号），S 为稀疏（异常），N 为噪声。
2. **秩约束鲁棒 PCA**（GoDec 型交替投影）：L 取秩 r 的最佳逼近；S 为按**每个波长单独估计噪声尺度**后、超过 5σ 的残差。
   - 不用经典 PCP 的原因：经典 PCP 分解出的 L 秩为 **426–446**，把噪声也吸了进去，没有真正分离出低秩结构（`q1_outlier_summary.csv` 的 `pcp_rank` 列）。
3. **异常帧**：判据是帧内标准化残差的均值，看的是光谱**形状**异常，不看整体亮度（整帧亮度闪烁是真实的火焰湍流）。连续超过 5 s 的“异常”视为工况变化（如吹炼末段），不判为异常。异常帧中只剔除偏离像素（|z| > 2.5），其余像素保留，用于确定该帧的低秩得分。
4. **连续化**：低秩补全得到每帧干净光谱 → SVD 得到 I(t, λ) = exp[μ(λ) + Σ aₖ(t) φₖ(λ)]。aₖ(t) 用平滑样条（GCV），φₖ(λ) 用三次样条，因此对任意 (t, λ) 都可求值。
5. 三维图展示的是**趋势曲面**（aₖ 用 λ = 10⁴ 强平滑），图题已标明；帧间闪烁的幅度另行量化（见下）。

## 2. 第二问：耗氧与烟气的重构、关系与时延

### 2.1 重构
| 项目 | 结论 | 出处 |
|---|---|---|
| **耗氧计数器拍频** | 计数器每次增量约 **4.73 m³**（10 炉一致），与记录仪时钟漂移，约每 **11 s** 漏记一次、随后补记双倍。直接差分得到的流量会剧烈振荡 | `q2_o2_counter_beat.csv`、`q2_curves_heat*.png` 左上图的灰线 |

### 2.3 数据一致性诊断（出彩点）
- 按题目的 m³/s 积分，生成 CO、CO₂ 所需的氧气 = 0.5·E_CO + E_CO2，是实际供氧量的 **5.46–6.53 倍**（均值 5.92），违反碳–氧守恒（`q2_mass_balance.csv`、`q2_mass_balance.png`）。

| 不对齐 | — | 0.208 |
| 常数时延 | L = 31 s | 0.243 |
| **输运模型（采用）** | **K = 170 m³，τ₀ 估计为 0** | **0.247** |
| 对照：CO+CO₂ 联合 / 仅 CO₂ | L = 69 / 72 s | 0.16 / 0.11 |

|---|---|---|---|---|---|---|---|

### ⚠ 需要人工判断（最重要）
1. **K 的 bootstrap 95% 置信区间很宽（0–400 m³）**，准则曲线比较平，输运模型与常数时延的预测力只差 0.004（bootstrap 中 77% 的情况输运模型更好）。论文的写法建议：函数形式 τ = K/Q 来自物理推导，K 由数据标定；流量依赖由窗口互相关（ρ = −0.75）给出强证据；如实报告不确定性。
2. 窗口估计显示的流量依赖**比 K/Q 更陡**（流量 5→5.5 m³/s 时，时延从 63 s 降到 31 s）。可在“模型改进”中提出幂律形式 τ = a·Q^(−b)，或考虑烟道内二次燃烧等因素。
3. 时延对第三问很关键：用错误的时延（例如 CO+CO₂ 联合标定得到的约 66 s）对齐，CO₂ 的预测 R² 会明显下降。

## 3. 第三问：光谱实时预测烟气

### 设定
- **预测目标**：y(t) = c(t + τ(t))，即 τ 秒后才会被分析仪测到的烟气。预测因此**提前约 30–40 s**。
- **输入**：只用 t 时刻及之前的数据。光谱取 SNV 归一化后的 5 s 滑动平均，经主成分（15 个）及其 10 s、20 s 均值和斜率；工艺特征为累积耗氧、24 s 因果流量和进度。
- **验证**：10 折留一炉（LOHO）。所有标准化、PCA、模型都只在训练炉上拟合。
- **最终模型 M4**：LightGBM，光谱 + 工艺 + 时延对齐 + 炉次归一化（减去本炉前 60 s 的平均光谱，实时可得）。

### 消融与组合（10 炉 R² 的中位数 / 均值 / 最差；`q3_summary_all_configs.csv`）

### 结论要点
1. **时延对齐必不可少**：M2 → M3，CO₂ 的 R² 均值从 −0.03 提高到 0.58。
2. **光谱的价值主要体现在 CO₂ 和过渡阶段**：
   - M0 → M4，CO₂ 的 RMSE 从 2.58 降到 2.35，最差炉的 R² 从 0.06 提高到 0.33。
   - 阶段断点 ±30 s 内，CO 的 RMSE 从 8.45 降到 7.93，CO₂ 从 3.08 降到 2.79；流量突变时刻，CO 从 7.18 降到 6.92（`q3_transition_rmse.csv`）。
   - 树模型的增益中，光谱特征占 12%（CO）和 25%（CO₂）（`q3_feature_importance.csv`）。
3. **组合方式**：整体组合（M4）最好。按 6B/6C 分组后，CO 的中位 R² 相当（0.883），但 CO₂ 明显变差，最差炉为负；单炉模型集成在 CO₂ 上更差（均值约 0.30）。论文的论述：10 炉样本有限，整体训练加“炉次归一化”比分组更能泛化。层次聚类结果见 `q3_cluster_dendrogram.png`。
4. **预测区间**：90% 共形区间的实际覆盖率为 CO 88.2%、CO₂ 88.8%，平均半宽分别为 10.4 和 3.9（`q3_conformal_coverage.csv`）。附件 1 的覆盖率偏低（CO 44%、CO₂ 58%），因为它的 CO 峰值（59）明显高于其他炉。
5. **在线校正**（迟到的实测值用于修正偏差，α = 0.5；`q3_online_correction_summary.csv`）：

|---|---|---|---|---|---|---|
| CO 的 R² | 0.919 | 0.909 | 0.897 | 0.886 | 0.877 | 0.846 |
| CO₂ 的 R² | 0.762 | 0.743 | 0.706 | 0.681 | 0.629 | 0.616 |

   结论：探头工作频率**降低到原来的 1/120**（每 2 分钟测一次）时，CO 的精度仍高于纯光谱预测，这直接回应题目“减少探头工作次数、延长寿命”的背景。

## 4. 与设计文档的差异（如实记录）

| 设计文档 | 实际做法 | 原因 |
|---|---|---|
| 第一问用经典 PCP 做 RPCA | 改为秩约束鲁棒 PCA | PCP 分解出的 L 秩为 426–446，没有分离出低秩结构 |
| 第一问异常帧整帧剔除 | 只剔除帧内偏离像素 | 整帧剔除后只能跨闪烁插值，重构误差反而更大 |

| 第二问用两个断点、三个阶段 | 三个断点、四个阶段（带物理约束） | 数据呈明显的四段形态 |
| 第二问用 CO 与 CO₂ 联合标定时延 | 以 CO 为时间标记 | CO₂ 准则曲线平坦且偏向长时延；按联合时延对齐会使第三问 CO₂ 的 R² 降到约 0.26 |
